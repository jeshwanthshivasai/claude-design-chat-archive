# Explainer video (Remotion)

A 68-second animated explainer for Design Chat Archive, in 16:9 (1920×1080) and 9:16 (1080×1920). It uses kinetic type and a synthesized soundtrack, with no voiceover. Every frame is drawn in code, and the screens are vector recreations of the real product with dummy hobby projects.

## Make it

```sh
npm install
python3 music.py                 # writes public/soundtrack.wav from src/timeline.json
npm run studio                   # preview in the browser
npx remotion render src/index.ts Landscape out/design-chat-archive-16x9.mp4 --crf=18
npx remotion render src/index.ts Portrait  out/design-chat-archive-9x16.mp4 --crf=18
```

`remotion.config.ts` points at a local Chromium; change or remove `setBrowserExecutable` on your machine.

## How it's put together

- **`src/timeline.json`**: the score.
  - 100 BPM, 72 frames per bar at 30 fps.
  - The scene start frames.
  - Every sound effect's frame.
  - Both the animation and `music.py` read it, so the stamps, clicks and cuts land on the beat. To change the timing, edit this file and run `music.py` again.
- **`src/scenes.tsx`**: the thirteen scenes, in order:

  | Scene | What it shows |
  |---|---|
  | Deadline | the date and the day ruler |
  | Loss | the chats break up |
  | Steering | the bubbles from a design chat |
  | Reveal | the logo, with the stamp |
  | Panel | the side panel, archiving |
  | Save chats | the button in the project toolbar |
  | Case study | a project's drafted case study |
  | Reader | searching every chat offline |
  | Prompts | the prompt library |
  | Wrapped | the shareable card |
  | Privacy | nothing leaves the browser |
  | CTA | the call to action |
  | End card | the closing frame |

  Each scene lays itself out for landscape or portrait.
- **`src/ui.tsx`**: the product screens. These are the side panel, the browser and toolbar, the toast, the case study, the reader, the prompt cards and the Wrapped card.
- **`src/primitives.tsx`**: the shared visual pieces:
  - the ruled ledger background
  - kinetic words, the typewriter and the counters
  - the folder mark, the rubber stamp and the cursor
  - the day ruler
  - the manila wipe between scenes
- **`music.py`**: the soundtrack, synthesized with numpy and scipy. It has a clock tick and pulse for tension, a lift into F major at the reveal, a plucked "filing" arpeggio, and sound effects for each stamp, click and whoosh.
